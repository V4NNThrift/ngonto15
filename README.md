## 🚀 QUICK START

</div>

### Step 1: Fork & Setup

<div align="center">

[![Fork](https://img.shields.io/badge/Fork-This%20Repo-F44336?style=for-the-badge&logo=github&logoColor=white)](https://github.com/V4NNThrift/ngonto15/fork)

</div>

### Step 2: Add Tailscale Secret

```
Settings → Secrets → Actions → New Secret
```

| Name | Value |
|:---:|:---:|
| `TAILSCALE_AUTH_KEY` | Auth key dari Tailscale Admin |

### Step 3: Run!

```
Actions → Yanzz Ubuntu → Run Workflow
```

<br />

<div align="center">

### Step 4: Connect via SSH

</div>

```bash
# Dari log GitHub Actions, copy IP Tailscale kamu
ssh runner@100.x.x.x

# Password: Evan123456
```
